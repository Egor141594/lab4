# Домашняя задание к работе 4  
## Условие задачи
Прибор на заводе имеет две контрольные лампы, соответствующие значениям датчиков A и B. Сирена тревоги должна загораться, если ровно одна из ламп показывает нечетное значение. Запишите условие для включения сирены.  
## Алгоритм и блок-схема  
### Алгоритм  
1.Начало  
2.Объявить переменные A и B(целые числа)  
3.Запросить у пользователя значения A и B  
4.Проверить условие: если одна лампа нечётная, а другая чётная((A % 2 != 0 && B % 2 == 0 || (A % 2 == 0 && B % 2 != 0)):  
Вывести: "Тревога"
Иначе:  
Вывести: "Нет тревоги"  
5.Конец
